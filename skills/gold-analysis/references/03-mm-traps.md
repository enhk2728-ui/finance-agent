# 做市商痕迹与陷阱 (MM Traps)

Al Brooks 方法论中，识别"谁被套了"是理解价格运动方向的关键。

## 核心思想

市场（做市商/机构）通过制造假象诱导散户入场，然后反向运动套住他们。被套的交易者被迫平仓时会推动价格进一步向反方向运动。

> 原著: "理解总在场内头寸的概念是关键——如果你不得不一直在场内，要么做多要么做空，那么当前你应该持有什么方向？"（反转篇，第15章）

## 陷阱类型

### 1. 假突破 (Fake Breakout) — 最经典
- 价格短暂突破关键区间（支撑/阻力）→ 迅速拉回 → 反向运动
- **做多陷阱**: 价格突破阻力 → 追多者入场 → 价格跌回 → 追多者止损 → 加速下跌
- **做空陷阱**: 价格跌破支撑 → 追空者入场 → 价格涨回 → 追空者止损 → 加速上涨

### 2. 弱势反弹/回调 (Weak Retracement)
- 反弹/回调不到前一波段的 **38.2%**
- 说明反弹/回调方无力
- 原趋势方向有更强动力，趋势大概率延续
- **38.2% 是关键的强弱分界线**

### 3. 三次测试失败 (Triple Test Failure)
- 同一阻力/支撑区间被反复测试 ≥3 次但始终未突破
- 每一次测试都是一次"突破尝试失败"
- 一旦最终突破，运动通常会非常猛烈（大量止损盘被触发）
- "市场有强烈的倾向去继续做刚刚正在做的事情，所以对于改变存在很强的阻力"（区间篇，第1章）

### 4. 双重顶/双重底陷阱
- 第一次测试形成结构 → 第二次测试看起来确认 → 第三次反向突破套住所有人
- 这是"三次测试"的变体

## 识别方法

```
假突破判断:
  price[i-1] 突破区间边界
  AND price[i] 回到区间内
  AND price[i] 与突破方向相反（SH突破→SL拉回，或SL突破→SH拉回）

弱势反弹判断:
  retrace_size / leg_size < 0.382

三次测试:
  区间 touches >= 3 且未有效突破
```

## 交易应用

- **跟随陷阱方向**: 假突破后，向反向交易（即做市商的真实方向）
- **陷阱确认后入场**: 等待价格确认回到区间内再入场，不要抢跑
- **三次测试后关注**: 准备捕捉最终突破的大行情

> 原著核心: "总在场内头寸"概念——如果陷阱套住了多头，总在场内头寸就变成了空头，因为被套的多头迟早要平仓卖出。
