# 测量运动与目标 (Measured Moves & Targets)

Al Brooks 方法论中精确的量度目标计算方法。市场往往会对关键价位做出精确反应。

## 测量运动类型

### 1. 基于尖峰 (Spike / First Leg)
- 基于第一条腿（尖峰）高度投射
- **MM 目标 = 尖峰起点 ± 尖峰高度**
- 用于判断趋势延续的目标位

```
上升尖峰: 目标 = 尖峰高点 + (尖峰高点 - 尖峰低点)
下降尖峰: 目标 = 尖峰低点 - (尖峰高点 - 尖峰低点)
```

> 原著（区间篇，第7章）: "市场时常会走出与第一条腿等长的第二条腿。这被称为测量运动（Measured Move）。"

### 2. 基于缺口 (Gap)
- 缺口区间的中点作为磁力位
- 缺口被填补后，价格通常会继续向原方向运动，目标 ≈ 缺口幅度

### 3. 基于交易区间 (Trading Range)
- 区间宽度向上/向下投射
- 突破交易区间后，目标 = 突破点 ± 区间宽度
- "区间越宽，突破后的运动越大"（区间篇，第21章）

### 4. 基于楔形/三推 (Wedge / Three Pushes)
- 三推等距：三推的每一段往往长度相近
- 第三推到尽头后反转，目标至少回到第一推起点

## 磁力位 (Magnet Levels)

> 原著（区间篇，第三部分）: "磁力位是价格倾向于被吸引到达的价位。"

| 磁力位类型 | 说明 |
|-----------|------|
| 前一波段的高/低点 | 最强的磁力位 |
| 尖峰测量目标 | 数学计算的目标位 |
| 缺口上/下沿 | 缺口天然吸引价格 |
| 整数关口 | XAUUSD: $3000, $3050, $3100... |
| 前日/前周高低点 | 时间锚定的磁力位 |
| 开盘价 | 日内交易的关键磁力位 |

## 目标达成后的常见行为

1. **精确到达后反转**: 价格精确触及 MM 目标后反转 → 强势信号
2. **穿越目标**: 价格轻松越过目标 → 趋势比预想的更强
3. **未到达目标就反转**: 趋势比预想的更弱 → 可能趋势结束

## 交易应用

- **止盈参考**: 将 MM 目标作为部分或全部止盈位
- **不要机械依赖**: MM 目标是"参考"，不是"保证"
- **结合结构**: 到了目标位 + 出现反转信号 = 高概率反转
