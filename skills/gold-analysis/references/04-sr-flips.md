# 支撑与阻力翻转 (SR Flips)

支撑变阻力、阻力变支撑——这是价格行为中最可靠的交易架构之一。

## 核心原理

- **旧支撑跌破后成为新阻力**: 曾经托住价格的区域，一旦跌破，再次回到时原来的买家变成了卖家（他们被套了，等着回本平仓）
- **旧阻力突破后成为新支撑**: 曾经压住价格的区域，一旦突破，再次回到时原来的卖家变成了买家（他们错失了突破，等着回调上车）

> 原著: "翻转区的强度取决于原区间的触碰次数和持续时间。被测试次数越多的区间，翻转后的支撑/阻力效果越强。"

## 翻转的等级

### 强翻转区
- 触碰 ≥ 5 次的原区间
- 持续时间长（跨越多个交易时段）
- 价格在此区间发生过激烈争夺（长尾线、大量成交量）
- **翻转后极大概率守住**

### 中等翻转区
- 触碰 3-4 次
- 有一定时间跨度
- 翻转后大概率守住，但需要确认

### 弱翻转区
- 触碰 2 次
- 时间跨度短
- 翻转后可能再次翻转回来（"混合区"）

## 翻转模式分类

### 支撑→阻力 (Support to Resistance)
```
原区间角色: 支撑（SL触碰）
价格行为: 价格跌破该区间
翻转后: 价格回到该区间时遇到卖压（SH触碰）
交易机会: 回测做空
```

### 阻力→支撑 (Resistance to Support)
```
原区间角色: 阻力（SH触碰）
价格行为: 价格突破该区间
翻转后: 价格回到该区间时遇到买盘（SL触碰）
交易机会: 回测做多
```

## 破位回测 (Breakout Retest)

这是 SR 翻转最常见的交易机会：

1. **突破确认**: 价格干净利落地突破区间（强趋势棒）
2. **回测**: 价格回到原区间附近
3. **确认**: 在原区间位置出现反转信号棒（pin bar / 外包棒 / 十字星+趋势棒组合）
4. **入场**: 确认信号棒被突破后入场

> 原著补充（区间篇）: "突破回撤是最可靠的入场架构之一。当市场回撤至突破点并形成反转信号时，这是一个高胜率的入场机会。"

## 交易应用

- **首要关注**: 触碰次数 ≥ 5 的区间发生翻转 → A 类交易机会
- **等待确认**: 不要预判翻转，等价格在原区间位置出现确认信号再入场
- **止损设置**: 放在原区间之外（给假突破留空间）
