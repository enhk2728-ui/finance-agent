# 突破与失败突破 (Breakouts & Failed Breakouts)

这是 Al Brooks 价格行为理论中**最核心的概念**。

## 核心原理

> 原著原文: "市场总是在尝试突破，然后又努力使每个突破失败。这是所有交易最根本的方面，也是我们所做的一切事情的核心。"（区间篇，第1章）

"每条趋势棒都是一个突破，在每条多头和空头趋势棒的顶部和底部都存在买家和卖家。对任何东西的突破都是相同的。有些交易者认为突破将会成功，并且据此下单，别的交易者则在反向下单，认为突破将会失败。交易者在研判一个突破是否会成功方面做得越好，那么他作为交易者的生活就越好。"

## 突破的分类

### 强突破 (Strong Breakout)
- 至少持续几棒的趋势棒（"坚持到底"/follow-through）
- 尾线很短（买卖双方没有犹豫）
- 实体大于 ATR 的 25%，且上下尾线 < 实体的 15%
- 强突破意味着"总在场内头寸"明确转为多头或空头

### 弱突破 (Weak Breakout)
- 突破棒实体小、尾线长
- 突破后立刻出现反向压力
- 没有 follow-through
- **大概率会失败**

### 失败突破 / FBO (Failed Breakout)
- 价格突破关键位后立刻折返
- 是**反转信号**：说明对方力量强
- 假突破 ≈ 做市商陷阱 → 套住追突破的交易者 → 反向运动
- "如果一个突破看起来比反转尝试更强，反转尝试将成为新趋势中一个旗形的起点"（反转篇，第1章）

### 突破回测 (Breakout Test)
- 突破后价格回到突破点区域测试
- **回测成功**: 价格在突破点获得支撑/阻力，趋势延续
- **回测失败**: 价格重新进入原区间，突破被否定

## 突破强弱判断

> 原著原文（区间篇，第2章）: "突破表现出来的强势征兆越多，突破就越可能成功。如果反转架构看起来比突破强得多，那么突破更有可能失败，市场将会反转。"

| 强势征兆 | 弱势征兆 |
|---------|---------|
| 实体大的趋势棒 | 小实体/十字星突破棒 |
| 尾线极短 | 长尾线 |
| 连续多根趋势棒（尖峰） | 单棒突破后立刻被压回 |
| 突破前有紧凑区间蓄力 | 突破前已有大幅运动 |
| 突破在关键时段（开盘/欧盘） | 在安静时段突破 |

## 交易应用

1. **顺势突破**: 在趋势方向上，突破回调位（旗形/回撤）后入场
2. **逆势假突破**: 识别失败的突破，反向入场
3. **突破回测**: 等待突破→回测→确认后再入场（更安全但可能错过）

> 原著核心: "所有交易归根结底都是在做这种决定——突破会成功吗？如果会成功，那么就准备在突破方向上交易。如果不成功，那么就准备在相反的方向交易。"
