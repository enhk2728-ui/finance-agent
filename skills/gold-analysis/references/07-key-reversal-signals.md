# 关键反转信号 (Key Reversal Signals)

Al Brooks 方法论中识别趋势反转的具体形态和信号。这些是最可靠的交易架构。

## 反转形态层级

### 第一级：强力反转信号（最可靠）

#### 高潮反转 (Climax Reversal)
- 大阳线/大阴线（实体 > ATR × 0.6）后紧接反向大棒
- V 形反转，最常见的趋势结束形态
- 价格行为逻辑：高潮棒耗尽最后的动能 → 另一方立刻接管
- **不需要二次确认**（因为高潮本身已经是最强的确认）

#### 楔形 / 三推反转 (Wedge / Three Pushes)
- 同一方向连续三推后力竭
- 常见于趋势末端
- "市场总是在第三次尝试时最容易反转"（反转篇，第5章）
- **三推等距**: 如果三推的幅度接近相等，反转概率更高

#### 双重顶/双重底 (Double Top / Double Bottom)
- 两次测试同一区域后反转
- 第二次测试时出现犹豫信号（长尾线、十字星）
- 突破颈线后确认

### 第二级：中等反转信号

#### 扩张三角形 (Expanding Triangle)
- 价格波动幅度越来越大
- 常见于趋势过渡期
- 最终从某一边突破

#### 最终旗形 (Final Flag)
- 趋势末端出现一个"看起来可以顺势入场"的旗形
- 入场后价格反向突破旗形（套住顺势交易者）
- "最终旗形是趋势末期的典型陷阱"（反转篇，第7章）

#### 外包棒/内包棒 (Outside/Inside Bars)
- **外包棒**: 当前K线的高/低完全包含前一根K线 → 短期的犹豫和转折信号
- **内包棒 (ii)**: 当前K线完全在前一根K线范围内 → 蓄力，准备突破
- **多棒形态**: ioi（内外内）/ oio（外内外）/ iioi（两内包后外包）→ 更强的转折信号

### 第三级：辅助反转信号

#### 十字星 / 犹豫棒 (Doji / Indecision Bar)
- 实体极小，上下尾线长
- 市场暂时失去方向
- 本身不是入场信号，但在关键位置出现 → 可能是反转前兆

#### 连续小阴小阳 / 紧凑通道 (Tight Channel)
- 实体很小的连续同向K线
- 往往是强趋势中的延续形态（不是反转信号!）
- 只有在通道变陡然后被反向突破时才视为反转

#### 20 缺口棒 (20 Gap Bar)
- 实体很大的趋势棒，高/低点与前一根棒的 EMA20 有较大距离
- 往往标志趋势高潮，可能接近末端
- 需要下一棒确认

## 确认规则

> 原著核心原则: "永远不要预判反转。等待价格证明它真的要反转。"（反转篇）

1. **信号棒**: 出现反转形态的信号棒
2. **入场棒**: 信号棒后的确认棒突破信号棒的高/低点
3. **入场**: 在入场棒突破时入场
4. **止损**: 放在反转形态的极点之外

## 反转强弱判断

| 强反转 | 弱反转 |
|-------|-------|
| 高潮后紧接反向高潮 | 单根反转棒无 follow-through |
| 三推等距楔形 | 不等距三推 |
| 双重顶/底在关键区间位置 | 在无人区形成的小双顶 |
| 反转前有明显的陷阱 | 无明显陷阱 |
| 反转棒实体大、尾线短 | 反转棒实体小、尾线长 |

## 交易应用

- **A 类交易**: 高潮反转 + 关键区间 → 最高优先级入场
- **等待确认**: 永远等信号棒被突破后再入场
- **逆趋势反转**: 只在趋势末期才考虑 → 参考 [[06-trend-maturity]]
